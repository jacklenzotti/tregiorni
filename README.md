# Tre Giorni — 3 Days in Italy

An interactive trip planner: build a personalized 3-day Italy itinerary from a curated
(and deliberately messy) dataset of 103 places. Browse and filter places, drop them into
day plans, auto-fill days, and watch opening-hours conflicts, travel times, and budget
estimates update live.

**Live:** https://tre-giorni.pages.dev

## Quickstart

```
npm install
npm run dev
```

## Scripts

`dev` · `build` · `test` · `lint` · `normalize` (regenerate canonical data + audit) · `deploy`
